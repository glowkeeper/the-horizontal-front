# Art development

This directory preserves visual-development artefacts that inform production
art without becoming runtime game assets merely by existing here.

Files under `concepts/` are exploratory research. They require explicit
selection, refinement, provenance review, catalogue integration and human
perceptual acceptance before any derived artwork can be marked
`production-approved`. Keep materially different drafts so later contributors
can inspect how and why the visual direction changed.

The preserved comparison currently contains:

- `concepts/the-monday-uprising-concept-sheet-v1.png` — the first dramatic,
  densely rendered exploration; and
- `concepts/the-monday-uprising-concept-sheet-v2-line-art.png` — the quieter
  editorial line-art alternative; and
- `concepts/the-monday-uprising-concept-sheet-v3-moderated.png` — the targeted
  return to sheet one with reduced environmental density; and
- `concepts/the-monday-uprising-concept-sheet-v4-comic-management.png` — the
  comic administrative-Management iteration; and
- `concepts/the-monday-uprising-concept-sheet-v5-angry-management.png` — the
  wounded-vanity and corporate-rage expression iteration.
